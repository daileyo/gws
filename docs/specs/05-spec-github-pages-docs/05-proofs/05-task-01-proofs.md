## Build Output

Command: `python -m mkdocs build`

```
 │ ⚠ WARNING – MkDocs 2.0 is incompatible with Material for MkDocs
 │
 │   MkDocs 1.x is unmaintained. We recommend switching to Zensical...
 │
INFO    -  Cleaning site directory
INFO    -  Building documentation to directory: /Users/daileyo/gws/personal/daileyo/gws/site

```

> **Note on warning**: The warning is generated by mkdocs-material 9.7.3 detecting that Homebrew's MkDocs 2.0 binary exists locally at `/opt/homebrew/bin/mkdocs`. The build uses pyenv's MkDocs 1.6.1 (via `python -m mkdocs`) and completes successfully. In GitHub Actions, only the pip-installed version will be present, so no warning will appear there. `requirements.txt` pins both `mkdocs==1.6.1` and `mkdocs-material==9.7.3` to ensure reproducible builds.
