# I've Got 99 Problems, but A.I. Ain't 1

*Building git-workspace — one spec, one commit, one soulless collaboration at a time.*

---

A blog series chronicling the creation of [git-workspace](https://github.com/daileyo/gws) (gws) — a cross-platform CLI tool for discovering, organizing, and navigating git repositories. Every post explores a real problem encountered during development and how AI-assisted collaboration shaped the solution. Expect honest assessments, actual code, and the occasional soulless joke.

Each post includes an **AI Scorecard** — a transparent rating of how AI performed on that topic — because if we're going to talk about building with AI, we should keep score.

## How to Read This Series

**Start from the top** for the full chronological journey, or **jump to any post** that catches your eye — each one stands on its own. Posts are grouped by category so you can find what matters to you.
