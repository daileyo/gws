# Homebrew packaging

Two formulae exist, for two different destinations. They are not interchangeable.

## What users install today

`brew install daileyo/tap/omgitworks`

That formula lives in the [daileyo/homebrew-tap](https://github.com/daileyo/homebrew-tap)
tap and is generated by GoReleaser on each release from the `brews:` block in
`.goreleaser.yml`. It downloads a **prebuilt binary**. Do not edit it by hand — it is
regenerated every release.

## `omgitworks.rb` in this directory

A homebrew-core **candidate**. It is not used by anything today.

homebrew-core does not accept prebuilt binaries: formulae must build from source, from an
immutable tag, with a checksum. So the tap formula can never be submitted as-is. This file is
the shape core requires, kept current so that submitting is a copy rather than a rewrite.

Before submitting, replace the two placeholders:

- `vVERSION` in the `url` → the release tag, e.g. `v3.0.0`
- `REPLACE_WITH_RELEASE_TARBALL_SHA256` → `sha256sum` of that tag's source tarball

### Verified

This formula has been built and tested locally against a source tarball:

```
brew install --build-from-source <tap>/omgitworks   # compiles, installs completions
brew test <tap>/omgitworks                          # 5 assertions pass
brew audit --strict <tap>/omgitworks                # clean
brew style <tap>/omgitworks                         # no offenses
```

Two problems were found and fixed by running it rather than reading it:

- `Utils.git_head` raises `RuntimeError: Not a Git repository` when building from a release
  tarball, which is exactly how core builds. Replaced with a static value.
- `std_go_args` already supplies `-s -w`, so passing them again produced
  `-ldflags=-s -w -s -w -X ...`.

## The blocker: notability

homebrew-core will not accept this project yet. Per Homebrew's
[Package Acceptance Policy](https://docs.brew.sh/Package-Acceptance-Policy):

| Requirement | Threshold (self-submission) | Status |
| --- | --- | --- |
| Repository age | ≥ 30 days | **263 days** ✓ |
| Licence | DFSG-compatible | **Apache-2.0** ✓ |
| Notability | 225 stars **or** 90 forks **or** 90 watchers | **0 / 0 / 0** ✗ |

Note the asymmetry: submission *by the owner* requires 225 stars, while a third party
submitting on the project's behalf needs only 75 stars, 30 forks, or 30 watchers. If the
project gains traction, the cheaper route is someone else opening the pull request.

Until then the tap is the supported install path, which Homebrew explicitly endorses:
software that does not meet the criteria "can generally be maintained in a third-party tap".

## Other channels

winget, Scoop, AUR, and Debian are tracked separately — see the distribution spec. Both
`omgitworks` and `omgw` were confirmed free on all of them.
